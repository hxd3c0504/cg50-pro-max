# 使用说明

## 打开计算器

访问 [CG50 Pro Max](https://cg50promax.up.railway.app)，等待页面完成首次资源加载。机身屏幕与放大的屏幕显示同一份内容，点击机身按键即可输入。

## 电脑键盘

| 键盘 | 计算器 |
| --- | --- |
| Enter | EXE |
| Backspace | DEL |
| Esc | EXIT |
| Tab / Home | MENU |
| F1–F6 | 对应功能键 |
| 方向键 | 对应方向键 |
| 单独按一下 Shift | SHIFT |
| 反引号 | ALPHA |
| F9 / F10 | 保存 / 恢复进度 |

数字及常见运算符可以直接输入；字母输入会按当前映射组合 ALPHA。浏览器或系统可能占用部分功能键，也可使用页面按钮。

## 设置与显示

齿轮按钮中可切换语言、主题与最近按键功能。最近按键默认关闭，开启后会占用一部分显示空间。小窗模式入口位于顶部工具栏。

## 进度与备份

进度保存在当前浏览器本地，不是账号云同步。在设置的「进度与备份」里可以保存、恢复和导出备份，F9、F10 也可用来保存和恢复。不同设备或浏览器之间不会自动共享进度；清除网站数据、隐私模式及浏览器存储回收都可能造成数据丢失。

顶部的“重载配置文件”会触发恢复初始状态流程，可能清除当前本机进度和设置；它不是普通刷新。操作前阅读确认提示并先留存备份。

## 遇到问题

先确认已等待资源加载，且只在一个窗口中使用同一来源的计算器。若仍异常，请在 [Issues](https://github.com/hxd3c0504/cg50-pro-max/issues) 提供设备、浏览器、操作步骤与现象。不要公开个人存档、密码或访问令牌。
