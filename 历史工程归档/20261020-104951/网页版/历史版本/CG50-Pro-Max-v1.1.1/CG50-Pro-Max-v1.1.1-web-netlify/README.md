# CG50 Pro Max V 1.1.1

This project contains the browser app and Netlify statistics functions.
Deploy with Netlify CLI: publish directory web; functions directory netlify/functions.
Do not upload this project to Netlify Drop: Drop does not deploy these functions.
Configure CG50_STATS_PASSWORD as a secret environment variable for Functions.
The management dashboard is /stats. Its password is not included in this project.

Automatic updates download and verify the complete app while preserving progress.
Manual Reload configuration requires confirmation and restores the initial snapshot.
