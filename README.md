# CG50 Pro Max

a free cg50 online version

在线使用：[CG50 Pro Max](https://cg50promax.up.railway.app)

- **当前网页版 1.2.5**：[web-app](web-app/README.md)，包含网页、Worker 适配、Railway 服务、更新机制及验证脚本。使用 Node.js 24+，先运行 `npm run assets`，再运行 `npm run preview`。
- [ipad](ipad/)：早期 iPad 工程与 Go 模拟器源码，保留供参考。
- [mac](mac/)：早期 macOS / Android 工程与研究资料，保留供参考。
- [docs](docs/)：原有项目资料。

当前网页版的部署和本地运行方法见 [web-app/README.md](web-app/README.md)。固件、状态与 WASM 不直接收录在 Git 中，资源准备脚本会按清单核验；账号凭据、数据库及个人进度不上传。
